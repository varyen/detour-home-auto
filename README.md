# Detour Home Auto

Приложение (бывшее WG Home Auto), которое **автоматически выключает VPN в домашней Wi-Fi сети и включает во всех остальных случаях** (другая Wi-Fi, мобильный интернет, отсутствие сети).

VPN встроен в приложение. С 3.0 движок — **mihomo** (собственное ядро `core/`, собирается gomobile), один на все протоколы:

| Протокол | Как добавить |
|---|---|
| WireGuard | файл `.conf` |
| AmneziaWG (1.0, 1.5, 2.0) | файл `.conf` с `Jc`/`Jmin`/`Jmax`/`S1…S4`/`H1…H4`/`I1…I5` |
| VLESS (Reality, TLS, ws, grpc, xhttp) | ссылка `vless://…` |
| Trojan, Shadowsocks, VMess, Hysteria2 | ссылка |

Подходят те же `.conf` и ссылки, что отдаёт панель Detour (свой VPN-сервер роутера, «ссылка на профиль»), а с 3.1 —
и **QR-код** из её настроек (кнопка «Сканировать QR-код»), и ключ AmneziaVPN `vpn://…`.
Профилей может быть несколько; вне дома включается отмеченный. Кнопка с датчиком меряет задержку через
профиль, не поднимая туннель. Ссылку `vless://` можно открыть прямо в приложении или «поделиться» в него.

## Как это работает

1. Foreground-сервис слушает смену Wi-Fi через `ConnectivityManager.NetworkCallback` и изменения настроек
   (список домашних сетей, строгий режим).
2. При каждом изменении читается SSID текущей сети.
3. Дома (SSID в списке «домашних») → туннель **выключается**.
4. Вне дома (чужая Wi-Fi / мобильный интернет / нет сети) → туннель **включается** с отмеченным профилем.
5. Туннель поднимает сам процесс приложения: свой `VpnService` (`DhaVpnService`) отдаёт fd интерфейса ядру.
   Само приложение из туннеля исключено (`addDisallowedApplication`), поэтому соединения движка к серверу
   идут мимо VPN без `protect()`.
6. `AllowedIPs` из `.conf` уважаются: при неполном списке в туннель уходят только эти сети и DNS не
   перехватывается. При полном туннеле DNS перехватывает движок (fake-ip) — имена резолвит сервер на той стороне.
   IPv6 заводится в туннель и там отбрасывается, чтобы не шёл мимо.

## Требования

- Android 8.0+, `minSdk 26`, `targetSdk 34`, ABI arm64-v8a / armeabi-v7a.
- APK отдельный на архитектуру, ~34 МБ: ядро mihomo большое (70 МБ без сжатия).
- Для определения Wi-Fi на телефоне должна быть **включена геолокация** (системный переключатель) — без неё
  Android не отдаёт SSID даже при выданном разрешении.

## Настройка (первый запуск)

1. **Добавить профиль**: карточка «Профили VPN» → **«Файл .conf»** или **«Ссылка»** (подставит из буфера обмена).
2. **Согласие на VPN**: при первом поднятии система один раз спросит разрешение — «ОК».
3. **Геолокация «Разрешать всегда»**: карточка с предупреждением → **«Разрешить «Всегда»»**. **Обязательно
   для автозапуска после перезагрузки телефона** (см. ниже).
4. **Отключить оптимизацию батареи**: кнопка «Отключить оптимизацию батареи».
5. Подключиться к домашней Wi-Fi и нажать **«Добавить текущую»** (можно несколько).
6. Включить **«Автоматический режим»**.
7. Проверить вручную: **«Поднять туннель сейчас»** — строка «VPN сейчас» станет «активен».
   Если что-то не так — **«Журнал движка»**.

## Защита от утечек

Тумблер **«Защита от утечек»** (по умолчанию включён) сокращает окно незащищённого трафика на переходе:
в строгом режиме VPN включается, даже пока вы дома, если **сигнал слабый** (гистерезис −70 / −80 dBm) или
**Wi-Fi без реального интернета** (`NET_CAPABILITY_VALIDATED = false`). Переключение асимметрично:
включение ~0.7 c (быстро), выключение ~4 c (без «мигания»).

> **Полная гарантия против утечек** — только системный kill-switch (Настройки → VPN → «Всегда включён»
> + «Блокировать соединения без VPN»), но он блокирует трафик и дома. Наш режим — компромисс.

## Разрешения — зачем каждое

| Разрешение | Зачем |
|---|---|
| `INTERNET` | Движок создаёт сетевые сокеты |
| `ACCESS_FINE_LOCATION` | Android отдаёт SSID Wi-Fi только приложениям с точной геолокацией |
| `ACCESS_BACKGROUND_LOCATION` | Геолокация «всегда»: чтение SSID в фоне и **запуск службы после перезагрузки** (Android 14+) |
| `FOREGROUND_SERVICE` + `..._LOCATION` | Постоянный мониторинг в фоне (сервис типа `location`) |
| `POST_NOTIFICATIONS` | Уведомление службы (Android 13+) |
| `RECEIVE_BOOT_COMPLETED` | Возобновление мониторинга после перезагрузки |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Освобождение от Doze для надёжной работы в фоне |
| `BIND_VPN_SERVICE` | Собственный VPN-сервис `DhaVpnService` |
| `ACCESS_WIFI_STATE`, `ACCESS_NETWORK_STATE` | Чтение состояния сети и уровня сигнала |
| `CAMERA` | Сканер QR-кода профиля (необязательно: камера спрашивается только при сканировании) |

## Автозапуск после перезагрузки

Начиная с **Android 14** foreground-сервис типа `location` нельзя запустить из фона, если у приложения нет
геолокации **«Разрешать всегда»** (`ACCESS_BACKGROUND_LOCATION`). После перезагрузки `BootReceiver` стартует
службу именно из фона, поэтому:

- **разрешение выдано** → служба поднимается сама, всё работает;
- **разрешения нет** → служба не стартует, приложение показывает уведомление «Detour Home Auto не запустился»;
  достаточно открыть приложение (тогда старт идёт из foreground и разрешён).

> В версии 2.0 в этом случае `startForeground()` бросал `SecurityException` и приложение **падало при каждом
> включении телефона**. С 2.1 сервис не стартует вместо падения.

## Сборка

### Ядро (один раз и при обновлении mihomo)
Нужны Go, Android SDK + NDK, JDK 17:
```powershell
pwsh core/build-android.ps1        # → app/libs/dhcore.aar (в git не хранится)
```
Тег `cmfa` обязателен: без него mihomo на Android читает `/data/system/packages.list`, обычному приложению
это запрещено, и tun молча не стартует (интерфейс есть, трафик уходит в никуда).

Проверка профиля с ПК, без телефона (в `core/`):
```powershell
go run -tags with_gvisor ./cmd/dhprobe <файл.conf|ссылка>
```

### Debug
```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
cd C:\www\wg-auto
.\gradlew.bat :app:assembleDebug
```

### Release (подписанный)
Нужны локальные (не в git) файлы `keystore.jks` и `keystore.properties` в корне проекта:
```properties
storeFile=keystore.jks
storePassword=<пароль>
keyAlias=<alias>
keyPassword=<пароль>
```
Затем:
```powershell
.\gradlew.bat :app:assembleRelease
```
APK: `app\build\outputs\apk\release\app-<abi>-release.apk`. **Храните keystore.jks — без него не выпустить
обновление.** Пакет остался `com.vtools.wghome`, поэтому 3.0 ставится поверх 2.x: старый `.conf` переносится
в первый профиль автоматически.

```powershell
adb install -r app\build\outputs\apk\release\app-arm64-v8a-release.apk
```

## Структура проекта

```
app/src/main/java/com/vtools/wghome/
  MainActivity.kt        — UI на Compose: профили, домашние сети, согласие VPN, разрешения
  MonitorService.kt      — foreground-сервис, NetworkCallback, логика вкл/выкл, гистерезис
  TunnelController.kt    — свой VpnService (DhaVpnService) + управление ядром: up/down/probe
  Profiles.kt            — профиль (JSON ядра) и разбор .conf/ссылок
  PendingImport.kt       — профили, пришедшие из других приложений
  WifiUtils.kt           — SSID, уровень сигнала, признак интернета
  SettingsRepository.kt  — настройки и профили (SharedPreferences), перенос конфига 2.x
  AppState.kt            — живой статус для UI
  BootReceiver.kt        — автозапуск после перезагрузки
core/                    — ядро на Go поверх mihomo (gomobile); cmd/dhprobe — проверка профиля с ПК
```

**Стек:** Kotlin 1.9.24 · AGP 8.5.2 · Gradle 8.9 · Jetpack Compose (BOM 2024.02.02) · Material 3 ·
mihomo 1.19.32 через gomobile.

## iOS (каталог `ios/`)

То же ядро (`Dhcore.xcframework`), интерфейс на SwiftUI, туннель — расширение Network Extension
(`DetourHomeTunnel`, packet-tunnel). Авторежим на iOS делает сама система: правила On-Demand
«в домашних SSID — отключить, иначе — подключить» работают и при закрытом приложении.
Строгого режима нет — уровень сигнала iOS приложениям не отдаёт.

Сборка на macOS с Xcode (проверено на macOS-ВМ, Xcode 26.6):
```sh
sh core/build-ios.sh      # ядро → ios/Frameworks/Dhcore.xcframework (если proxy.golang.org недоступен — DHA_GOPROXY, см. скрипт)
sh ios/build.sh           # xcodegen + xcodebuild archive + ldid → ios/build/DetourHomeAuto-<версия>.ipa
```
Подписи Apple нет: entitlements (`networking.networkextension`, `wifi-info`) вшивает `ldid`, ставится через
TrollStore. Для обычной установки нужен платный аккаунт Apple Developer — без него Network Extension iOS не даёт.
